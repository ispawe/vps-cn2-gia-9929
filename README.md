## 线路怎么选：四档，价格能差四到六倍

建站 VPS 的分水岭在线路，不在 CPU。同样是 1 核 1GB，走国际线路和走 CN2 GIA，年付价能差出四到六倍。

**国际线路（BGP/Global）**
走普通公网，最便宜，国内访问延迟高，晚高峰容易丢包。适合访客全在海外，或者纯粹练手测试。拿它给国内用户建站，后台登录都要等。

**9929 + CMIN2**
联通 AS9929 加移动 CMIN2，电信、联通、移动三网都有优化。价格比国际线路高、比 CN2 GIA 低，是多数中文站长的性价比选择。晚高峰表现明显好于国际线路，但不如 GIA 稳定。

**CN2 GIA**
电信精品网，三网回程走 GIA。晚高峰相对稳，代价是贵。美西 CN2 GIA 到国内延迟通常在 150–180ms，第三方测评记录的 AkkoCloud 圣何塞延迟约 168ms，属于这个区间的正常水平。香港走 CN2 GIA 能压到 10–30ms，价格是另一个量级。

**香港直连**
CN2、PCCW、HKBN 都算，延迟最低，价格最高。适合对响应速度敏感的业务。

**国内机房**
延迟最低、带宽最贵，所有国内机房都需要备案。这一条能直接筛掉一半人的选项。

AkkoCloud 的三个机房都归在第三档（CN2 GIA），但方向不同：圣何塞是常规美西线路，法兰克福和伦敦是欧洲方向。市面上做美西 CN2 GIA 的商家很多，把德国和英国机房也接上 CN2 GIA 回国的商家则少得多。如果你的用户在欧洲、或者业务需要欧洲 IP 落地，这条线路的价值才真正体现出来；用户全在国内，欧洲机房只会比美西更远。

## 按场景选：四类站点分别要多少配置

下面这套门槛是经验口径，不是官方要求，不同程序、不同插件组合会有出入，但足以用来排除明显不够用的方案。

**个人博客、静态站、练手项目**
1 核 / 512MB–1GB 内存 / 5–10GB 硬盘 / 500GB 月流量。静态站和轻量 CMS 在这个配置上跑得很轻松。AkkoCloud 的 A1 mini（¥299/年）正好卡在这一档。

**WordPress 个人站**
1–2 核 / 2GB 内存 / 20GB 硬盘 / 1TB 月流量。这个组合是跑 WP + MySQL + PHP + 几个常用插件的舒适区。1GB 内存能跑起来，但缓存插件、安全插件一起上就开始吃紧。

**企业官网、带少量图片**
2 核 / 2–4GB 内存 / 20–30GB 硬盘 / 1–2TB 月流量。图片多的话硬盘往下压不住，备份也占空间。

**WooCommerce 商城、多站点**
2–4 核 / 4GB 内存起 / 30GB 硬盘以上 / 2TB 以上流量。商品图和订单数据会持续增长，硬盘和流量都要留余量。

## 下单前必须确认的六件事

这部分是本文最该看的地方。前面讲的是怎么挑，这里讲的是买完才发现会难受的坑。

**1. 续费是不是同价**
很多商家的低价是首期优惠，第二年按原价续。循环优惠码（recurring）才决定续费价，一次性优惠码只影响第一期。AkkoCloud 目前没有长期通用优惠码，标价即售价的可能性大，但下单前仍要在结账页确认续费金额，别只看首期。

**2. 流量跑完是断线还是限速**
有的商家直接停网，有的降速继续跑。DMIT 在 Pro 和 EB 系列上的做法是流量跑完不断线，把带宽降到 100Mbps–1Gbps，站点还能访问——这对建站用户差别很大，某个月多跑几个 G 不至于直接挂站。AkkoCloud 这一条没有公开资料，需要问客服。

**3. 流量怎么算**
AkkoCloud 官方标注流量为**双向计算**，入站也占额度。600GB 的月额度不等于 600GB 出站流量，实际可用的出站部分要打折扣。图片站、下载站、有大量 API 请求的站点，这一条要先算清楚。

**4. IP 被封了怎么办，换一次多少钱**
国内方向 IP 被墙是低概率但真实存在的风险。DMIT 的政策是每 15 天免费换一次，之后每次 $5。这类条款通常只写在 FAQ 或工单回复里，买之前问一句，比出事之后再问强。

**5. 退款窗口和用量限制**
DMIT 的做法是 3 天内无条件全额退款（用量不超过 30GB）、30 天内按剩余时间和流量折算部分退款。**AkkoCloud 的退款政策在公开资料里没有明确条款**，年付 ¥299 虽然不是大钱，但一次性付一年之前，退款边界值得先确认清楚。

**6. 能不能降级、能不能换机房**
多数商家支持补差价升级，不支持降级，换机房要重新购买。DMIT 就明确写了不支持降级、不能直接换机房。所以正确顺序是先买低配试线路，确认满意再升级；反过来走不通。

另外两条容易忽略的：

- **不保证原生 IP**。AkkoCloud 官方明确说明不保证原生 IP，Looking Glass 的测试 IP 也不代表你实际会分到的段。冲着解锁流媒体去的，别指望。
- **工单有时间窗**。官方公告写的是上班时间 12:00–22:00，工作时间内提交的问题 24 小时内答复、48 小时内解决，非工作时间由值班人员处理。夜里出故障，响应会慢一些。
